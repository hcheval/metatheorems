# `docs/notebook/`

Prose moved out of the sources during a documentation pass: development history, diagnoses of
problems that have since been fixed, and running commentary that described the code at a
moment that has passed.

Nothing here is deleted, and nothing here is authoritative. Each file is named after the module
the material came from, and the module usually carries a one-line pointer back to it. If a
statement here contradicts the code, the code is right.

The *reasoning* that is still live was left in the sources or is in `ARCHITECTURE.md`; what is
collected here is the part that only made sense to someone who was there.
